# Launch kit

One file per release, so the copy for a version lives in one place.

## How to use it

1. Copy `TEMPLATE.md` to `growth/launch-kit/vX.Y.Z.md`, using the real version (for example `v1.2.0.md`).
2. Fill in each section from what is actually in the release: the changelog, merged PRs and the code.
3. Work through the pre-publish checklist at the bottom of the file.
4. Hand the finished file to the CMO for the content calendar.

## What is in a kit

- One-line summary
- Three user-facing highlights
- A short LinkedIn post draft, following `growth/linkedin/voice.md`
- Store "What's new" text
- A changelog entry
- A pre-publish checklist

## Ground rules

- A kit is a draft. Nothing here publishes anything.
- Only the LinkedIn autopilot posts on its own. Any other public post (Reddit, Hacker News, Product Hunt, press, replies to users) needs CEO review first.
- This repo is public. No pricing, money, legal, personal or strategy details.
- Wellbeing wording is about habits (breaks, water, rest, focus), never health outcomes or therapy.
